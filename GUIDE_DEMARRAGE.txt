  Microservices Demo avec Rôles

📋 PRÉREQUIS
✅ Java 17+
✅ Maven 3.8+
✅ Node.js 18+
✅ PostgreSQL 15+ (avec toutes les bases créées)
✅ Docker (pour Keycloak - optionnel)

========================================
🚀 ORDRE DE DÉMARRAGE DES SERVICES
========================================

1️⃣ EUREKA SERVER (Port 8761)
   cd eureka-server
   mvn spring-boot:run
   
   Vérifier: http://localhost:8761

2️⃣ API GATEWAY (Port 8080)
   cd api-gateway
   mvn spring-boot:run
   
   Vérifier: http://localhost:8080

3️⃣ AUTH SERVICE (Port 8081)
   cd auth-service
   mvn spring-boot:run
   
   ⚠️ IMPORTANT: Ce service crée automatiquement 3 utilisateurs de test

4️⃣ COURSES SERVICE (Port 8082)
   cd courses-service
   mvn spring-boot:run

5️⃣ STUDENT SERVICE (Port 8083)
   cd student-service
   mvn spring-boot:run

6️⃣ COMPLAINTS SERVICE (Port 8084)
   cd complaints-service
   mvn spring-boot:run

7️⃣ CLUBS SERVICE (Port 8085)
   cd clubs-service
   mvn spring-boot:run

8️⃣ QUIZ SERVICE (Port 8086)
   cd quiz-service
   mvn spring-boot:run

9️⃣ FRONTEND ANGULAR (Port 4200)
   cd frontend
   npm install (première fois seulement)
   ng serve
   
   Accéder: http://localhost:4200

🎯 FONCTIONNALITÉS PAR RÔLE
========================================

ADMIN (Administrateur):
  ✅ Gérer tous les utilisateurs
  ✅ Créer/Modifier/Supprimer des utilisateurs
  ✅ Changer les rôles
  ✅ Accès complet à toutes les fonctionnalités

TUTOR (Tuteur):
  ✅ Gérer les étudiants
  ✅ Gérer les inscriptions aux cours
  ✅ Voir les statistiques
  ❌ Pas d'accès à la gestion des utilisateurs

STUDENT (Étudiant):
  ✅ Voir les cours disponibles
  ✅ Créer des réclamations
  ✅ Rejoindre des clubs
  ✅ Passer des quiz
  ❌ Pas d'accès à la gestion des étudiants
  ❌ Pas d'accès aux inscriptions

========================================
📝 CRÉATION D'UN NOUVEAU COMPTE
========================================

Via l'interface:
1. Cliquer sur "Pas de compte ? Créer un compte"
2. Remplir le formulaire
3. Le rôle par défaut est STUDENT
4. Seul un ADMIN peut changer le rôle via la page Utilisateurs

Via API:
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username":"newuser",
    "email":"newuser@demo.com",
    "password":"password123",
    "firstName":"New",
    "lastName":"User",
    "role":"STUDENT"
  }'

========================================
🛠️ DÉPANNAGE
========================================

Problème: Service ne démarre pas
Solution: Vérifier que la base de données existe et que PostgreSQL est lancé

Problème: Erreur de connexion frontend
Solution: Vérifier que tous les services backend sont démarrés

Problème: Page blanche sur le frontend
Solution: Ouvrir la console du navigateur (F12) pour voir les erreurs

Problème: "Accès refusé" sur une page
Solution: Vérifier que vous êtes connecté avec le bon rôle

Problème: Services non visibles sur Eureka
Solution: Attendre 30 secondes après le démarrage
